# Python Practice

This repository contains my **Python practice and experiments**.

I use Python for DSA, but DSA alone does not give me a deep understanding of the Python language. So, alongside my DSA practice, I am using this repository to learn and practise **Python itself**.

The focus here is on understanding Python's features, behaviour, and programming concepts through small scripts and experiments.

## Why This Repository?

I want to move beyond simply knowing Python syntax.

```text
Using Python
     ↓
Understanding Python
     ↓
Writing better Python
```

This repository is where I practise that process.

I will use small scripts to explore things such as:

* Python fundamentals
* Variables and data types
* Strings and operators
* Lists, tuples, sets, and dictionaries
* Slicing and comprehensions
* Functions
* Scope and namespaces
* `*args` and `**kwargs`
* Object-oriented programming
* Classes and objects
* Inheritance and composition
* Magic/dunder methods
* Iterators and generators
* Decorators
* Context managers
* Exceptions and error handling
* Modules and packages
* File handling
* Type hints
* Dataclasses
* Descriptors
* Testing and debugging
* Standard library features
* Clean and maintainable Python code
* Other Python features I encounter while learning

## How I Practise

Each concept is explored through **small Python scripts**.

Instead of only reading about a feature, I try to understand:

```text
What is it?
    ↓
Why does it exist?
    ↓
How does it work?
    ↓
How does Python behave?
    ↓
When would I use it?
    ↓
What happens in edge cases?
```

The scripts may be very small. That is intentional.

A simple script that helps me understand one Python behaviour is more useful to me than a large program that I do not fully understand.

## Learning Through Experiments

Many scripts in this repository are experiments rather than complete applications.

For example, I may create a small script just to understand:

```python
a = [1, 2, 3]
b = a

b.append(4)

print(a)
```

The purpose is not to build something useful.

The purpose is to understand **why `a` changes when I modify `b`**.

I will use this approach for Python features that are easy to misunderstand or memorise without actually understanding them.
